# FocusFlow

A modern study assistant app built with :contentReference[oaicite:0]{index=0} to help students stay organized, study smarter, and improve productivity.

Created for a university app development contest.

---

## Features

- Study session tracking
- Smart revision tools
- Task and homework management
- Clean and modern user interface
- Personalized study assistance
- Fast and responsive Android experience
- Flashcards and quizzes
- Cloud sync
- User accounts
- Firebase backend integration

---

## Built With

- Java / Kotlin
- Android Studio
- XML
- Gradle
- Firebase

## Installation

1. Clone the repository

```bash
git clone https://github.com/johnshoko-byte/study-assistant-andriod-app.git
```

2. Open the project in Android Studio

3. Sync Gradle files

4. Run the app on an emulator or Android device
